Codjingrank API contract

Thiết kế API v2.1 cho frontend: 94 endpoint, gồm 42 learner và 52 admin, bao phủ F01–F13.

Target contract dành cho mock. Các endpoint /api/v1 chưa được triển khai trong backend. Trang này không phải địa chỉ API server.

Learner API — 42 endpoint Full API — learner và admin

Quy tắc tích hợp

  • Gateway là public entrypoint; prefix /api/v1, ID UUID, JSON camelCase.
  • Success: {status, code, message, data}. Error: {status, code, message, error, details}. HTTP 204 không có body.
  • Access token qua Bearer; refresh token qua HttpOnly cookie. Gửi credentials: include, không gửi X-User-*.
  • Run sample đồng bộ. Submit trả Pending, frontend poll tới verdict.
  • AI review chỉ sau Accepted đã persist; điểm AI không đổi verdict hoặc leaderboard.
  • Should/Could là phạm vi thiết kế, không phải cam kết đã triển khai.

Mock tại máy frontend

Tải OpenAPI learner hoặc OpenAPI đầy đủ, rồi chạy:

npx --yes @stoplight/prism-cli@5.16.0 mock openapi_fe.yaml -p 4010

Mock stateless: không lưu dữ liệu, thực thi code, kiểm tra quyền thực tế hay tự chuyển trạng thái job. Dùng Prefer: example=empty hoặc các ví dụ trạng thái được khai báo trong endpoint.
