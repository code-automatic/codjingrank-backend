# VPS deployment status

The previous VPS guide described the retired application, domains, GitHub App
and Vite frontend. Those deployment instructions have been withdrawn.

Use [deployment status](DEPLOYMENT.md) for the retained stack and integration
limits. A production guide must be written after UUID/schema integration,
Gateway `/api/v1` routing and the new frontend are implemented and tested.
Do not reuse old domains, TLS files or callback URLs as defaults.
